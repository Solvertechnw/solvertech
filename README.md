# Solver Tech Portfolio

Premium responsive portfolio positioning Solver Tech first as a Full-Stack Developer / Django specialist, with UI/UX, mobile, digital management, and hosting capabilities.

## Before deploying
1. Replace the `YOUR PHOTO` placeholder with your professional image.
2. Replace the `ST` logo slot with your actual Solver Tech logo.
3. Replace `YOUR_EMAIL@example.com`.
4. Update GitHub and LinkedIn URLs.
5. Add your real project screenshots and project links.

## Vercel
This is a plain HTML/CSS/JS site. Upload to GitHub and import the repository into Vercel. No build command is required.
